# 智慧树 / AI 智慧课程 自动连播脚本

两个 Tampermonkey（油猴）用户脚本，用于在课程视频播放结束后自动进入下一节，并把播放状态、完成状态做成可观察的日志。

> 仅用于个人学习效率工具，请遵守所在平台的使用条款。脚本不破解验证码、不伪造学习时长、不代答题目；是否能记录进度取决于平台自身的判定。

## 适用页面

| 脚本 | 适用平台 | 页面特征 |
| --- | --- | --- |
| `redhistory.js` | 智慧树 AI 教学中心（`*.polymas.com`、`*.zhihuishu.com` 旧版课程页） | 左侧为 `el-tree` 目录，节点带 `data-key`，完成后百分比消失或打勾 |
| `wulishang.js` | AI 智慧课程 / 新形态课程（`ai-smart-course-student-pro.zhihuishu.com`、`smartcoursestudent.zhihuishu.com`） | 左侧是“知识模块 → 知识单元 → 知识点”三级折叠目录，进度显示为 `必学 x/y` |

## 功能

- 视频播完自动点击目录中的下一节，并自动开始播放
- 跨“知识单元 / 知识模块”自动展开并继续
- 以平台接口为准判断“是否记为完成”，未完成时重播要求片段（而不是整段重来）
- 视频加载失败（网络 / 代理拦截）自动重试
- 后台标签页用 Web Worker 计时，避免被浏览器节流
- 右下角状态标签：显示当前识别结果与已切换节数，点击可暂停 / 恢复

## 安装

1. 浏览器安装 **Tampermonkey** 扩展（Chrome / Edge 商店均可）
2. 打开油猴面板 → **添加新脚本**
3. 删除编辑器默认内容，粘贴对应 `.user.js` 文件全文
4. `Ctrl + S` 保存
5. 打开课程页面并**刷新一次**（脚本只在页面加载时注入）
6. 右下角出现 `▶ …` 标签即表示已接管

> Chrome 新版需要在 `chrome://extensions` → Tampermonkey → 详情 中打开 **“允许用户脚本”**，否则脚本不会执行。
>
> 两个脚本的作用域名不同，一般不会同时生效；若手动同时启用，请只保留与当前页面匹配的那一个。

## 使用

脚本加载后自动运行，无需额外操作：

1. 正常播放视频
2. 播放结束 → 等待平台记录完成状态
3. 自动进入下一节并继续播放
4. 全部结束后标签显示“全部完成”

### 常用命令（浏览器控制台）

```js
__ZHS__.version      // 当前脚本版本
__ZHS__.status()     // 运行状态、视频状态
__ZHS__.why()        // 当前识别到的目录项与下一节
__ZHS__.next()       // 立即尝试切换下一节
__ZHS__.pause()      // 暂停自动连播
__ZHS__.resume()     // 恢复
__ZHS__.reset()      // 清空本地状态并刷新页面
```

`wulishang.js` 额外提供：

```js
__ZHS__.api()        // 接口判定结果：当前/下一知识点、资源完成度
__ZHS__.headers()    // 识别到的目录标题
__ZHS__.steps()      // 最近的操作步骤（排查卡住时用）
__ZHS__.tryNext()    // 立即尝试进入下一知识点
__ZHS__.probe()      // 导出目标行的 HTML，便于适配
```

## 配置

脚本开头的 `CFG` 可直接修改，保存后刷新生效：

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `rate` | 播放倍速 | `1` |
| `muted` | 静音播放（后台自动播放更稳定） | `true` |
| `keepPlaying` | 被暂停时自动续播 | `true` |
| `autoNext` | 播完自动下一节 | `true` |
| `completeWaitMs` | 等待平台记录完成的上限（毫秒） | `12000` |
| `maxReplay` | 未记为完成时重播次数 | `2` |
| `videoRetry` | 视频加载失败重试次数 | `3` |
| `badge` | 是否显示右下角标签 | `true` |

## 工作原理

- **目录识别**：按页面结构解析目录项（`el-tree` 节点 / “必学 x/y”行 / 知识点清单）
- **当前进度**：优先读取平台接口（知识点的 `studyProgress`、资源的 `studyStatus`、`schedule`），DOM 仅作兜底
- **切换动作**：模拟 `pointerdown / mousedown / pointerup / mouseup / click` 事件序列，并在失败时重试
- **完成判定**：接口返回 `studyStatus = 1` 或 `schedule = 100` 视为完成；无数据时按已完成处理，避免无限重播

## 常见问题

**F12 打开后停在“已在调试程序中暂停”**

页面带反调试代码（`debugger`）。按 `F8` 继续，或按 `Ctrl + F8` 停用断点；同时取消勾选 DevTools 右下角的“在抛出异常时暂停”。

**控制台出现 `NotAllowedError: play() failed …`**

浏览器自动播放策略限制。脚本会在 `play()` 前强制静音，通常不会再出现；如仍出现，手动点一次播放器即可。

**出现 `ERR_FAILED` / `CORS policy … address space`**

视频 CDN 被代理解析到内网地址，被 Chrome 的 Private Network Access 拦截。将以下域名设为直连（或关闭代理的 fake-ip）：

```
*.aliyuncs.com
*.zhihuishu.com
*.polymas.com
```

**提示“未识别目录”**

目录被折叠或页面尚未加载完。刷新后等待几秒；仍不行可在控制台执行 `__ZHS__.scan()` / `__ZHS__.probe()` 查看结构。
